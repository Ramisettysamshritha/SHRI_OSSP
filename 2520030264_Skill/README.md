# Skill-1: Process Abstraction

## Objective
To understand Linux system programming using `fork()` and `exec()` system calls.

## Files
- `fork.c` – Parent and child process creation
- `exec.c` – Demonstrates the `exec()` family
- `Makefile` – Compiles the program using `make`

## Commands
```bash
gcc fork.c
./a.out
make
